Printed fixtures (STL index)

46 files, all modelled in millimetres and checked as watertight single bodies. Extents are the bounding box as exported (X × Y × Z). Unless the build status marks a part tested, it has only been verified in software.

Printing: Creality Print 7.3, 260 mm bed. Templates print router face down, 2–3 walls, 10–15% infill, no supports. For the 3MF files, if the modifier doesn't come in, import the body and its _CORE100 STL together as one object, set the core to Modifier, and give it 100% infill.

# Retired code

Scripts and tools that were taken out of use. Nothing here runs, and the paths inside them are the ones they had when they ran, so most would fail if started from here.

| Folder | Was |
|---|---|
| `anyrail-prototype/` | The first AnyRail plan reader, from `tools/anyrail/prototype/` |
| `ap-electrical/` | The electrical drawing and SOQ build scripts, from `docs/ap/electrical/` |
| `benchwork-docs-scripts/` | The main-level and staging-level drawing scripts, from `docs/benchwork/` |
| `benchwork-tools/` | Helix, main-level and station-map 3D generators, from `tools/benchwork/` |
| `card-pipeline/` | Car-card scripts that `bin/cars` replaced, from `ops/hart-ops/card_pipeline/` |
| `cats-scripts/` | Old CATS desk builders (Digicon, CP panels, West Yard sheets) |
| `f-root-review/` | The local review desk for the old Desktop files, from `www/` |
| `jmri-scripts/` | Old JMRI scripts for the linear layouts and the hart panel |
| `nexttrain-dispatcher/` | The NextTrain dispatcher workbook export |
| `roster-sync/` | The DecoderPro roster copy from the Pi to the Mac and Windows and its helpers, from `tools/hosts/`; retired once the repo held the roster master (ADR-039) |
| `schematic-experiments/` | A one-band schematic solver experiment |
| `speedmatching/` | Speed-match and profile scripts, from `docs/jmri/speedmatching/` |
| `status-split/` | The one-time STATUS.md to `wiki/status/` split (ADR-038) and its test, from `tools/ops/` |
| `tables-scripts/` | Two old tables.xml scripts |
| `wiring-refresh/` | The wiring workbook refresh scripts, from `tools/wiring/` |

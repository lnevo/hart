There is no mDNS reflector: the MT300's own avahi (throttle side only) announces a stand-in, `My JMRI Railroad` at host `RPi-JMRI.local` = 10.42.0.2 (`/etc/avahi/hosts` and `services/jmri.service`), which its firewall forwards to the Pi. So `RPi-JMRI.local` works on both networks, and WiThrottle discovery works (renamed from `jmri-railroad.local` 2026-11-11). Avahi allows one static name per address (a second gives "Local name collision"), and turning a reflector on would clash with the Pi's own `RPi-JMRI.local`. Its firewall lets clients reach the house only on JMRI web 12080, WiThrottle 12090 and STS 8980 (opened 2026-11-11, with a 10.42.0.2 forward like JMRI's). MQTT is not needed from there. The LCOS mimic runs inside JMRI on the Pi at `/web/mimic/` (port 12080, already open), with `mimic_relay.py` publishing its clicks. The JMRI home page's STS and mimic links follow the page's host on the Pi; the Windows deploy points them at `RPi-JMRI.local` (the Pi's own mDNS name, so they work while JMRI is down); on the Mac they follow the page's host to the Mac's own development copies (STS on 8980, the Mac mimic server on 8765), so `http://localhost:12080` links to `localhost`. Do not share the Mac's internet over Ethernet into it: its DHCP switches off when it sees another DHCP server.
- **MQTT startup race:** Expect `ConcurrentModificationException` with `Can't subscribe` at startup: a JMRI race that drops the broker for a few seconds, then reconnects and resubscribes on its own (seen on the Mac 2026-10-31, on the Pi 2026-09-06). Retained messages alone trigger it, with no HART scripts running. Worry only if `Succeeded to reconnect` does not follow.
- **CATS load risk:** a turnout report during panel load can raise `NullPointerException ... requestLockClear` and kill the CATS event thread, freezing occupancy and turnout control. Do not move turnouts while CATS starts. If that error appears or occupancy stops updating, restart CATS. After CATS starts, use Appearance → Refresh Screen. Never use Refresh Layout: it can move points to a stale route.

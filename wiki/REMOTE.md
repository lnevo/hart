# Remote communication (while away)

iMessage from the agent often times out (macOS Messages privacy for Cursor/Terminal). Prefer these channels:

| Channel | How |
|---------|-----|
| **This Cursor chat** | Best — replies land in the session |
| **`wiki/STATUS.md`** | Agent writes progress / blockers; you leave answers under “Human replies” |
| **GitHub** | Comment on the branch / open an issue on [lnevo/hart](https://github.com/lnevo/hart) |
| **iMessage** | Optional; agent tries `scripts/imessage_lnevo.sh` — enable Messages access for Terminal/Cursor if you want it |

When you leave, say “keep going” and check `wiki/STATUS.md` when you return.

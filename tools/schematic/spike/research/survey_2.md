## 5. Multi-deck symbol conventions found
- Hidden/staging track: dashed line (NEK M1; St Charles from pass 1; PRR GO 418 uses dashed only for time-phased cutovers, so dashes are not universal). 
- Staging group: boxed label listing the off-layout places it represents (NEK).
- Continuation to another band or sheet: circled letter plus arrowhead (NEK); boxed letter on the line (St Charles); numbered "To X (n)" matched at the far end (WPMRM).
- Elevation: boxed inches on the track (WPMRM, Ridgely).
- Helix: drawn as rings/spiral with the word "Helix" (WPMRM, Ridgely); "Up"/"Down" labels or "Up to 2nd level"/"Down from 2nd level" colour pair (VMRR).
- Reversing loop / continuous run: drawn as an actual loop of the line (Willow Creek, pass 1); NEK avoids loops entirely by using staging stubs; the SAT paper permits vertical lines only for balloon loops.
- Terminal: filled dot (NEK) or buffer bar/short tick (PRR sheets).
No source gave a single standard helix glyph for a schematic; each uses words.

## 6. CATS Designer constraints (TEXT from the Designer User Guide, https://cats4ctc.wdfiles.com/local--files/main:userguides/DesignerManual.pdf, plus SEEN figures)
Verified in the manual (p.10-13, 52-64, 81, 87) and confirmed in source (tools/cats/src-repo/cats/src/cats/layout/items/Track.java, the local clone of https://bitbucket.org/Kb0oys/cats/src/master/).
- Panel is a rectangular grid of cells (columns by rows) that can be inserted/deleted, copied and pasted; rows/columns are the integer grid.
- A cell holds track, a label, a picture, a button, a station icon, or combinations, except picture excludes track/label.
- Track inside a cell: any of six segments, each running mid-edge to mid-edge, no curves: VERTICAL (top-bottom), HORIZONTAL (left-right), UPPERSLASH (left-top), LOWERSLASH (right-bottom), UPPERBACKSLASH (right-top), LOWERBACKSLASH (left-bottom). Several can coexist in one cell.
- Consequence: a diagonal is two quarter-cell pieces; a 45-degree step of one row consumes one column and the adjoining cells in two rows (SEEN in manual Figure 35, p.62: parallel tracks in rows 2 and 3 joined by an X within one column). Parallel tracks one row apart can be linked by a one-column diagonal; there is no half-row offset.
- Connectivity is by shared cell edge: segments that end on the same edge are joined. Two or three tracks meeting on one edge are recognised as switch points; exactly two complementary tracks meeting on an edge may be a crossing or a double slip and designer asks which (p.62-63). Crossings only if both touching cells have only two tracks and the segments are complements (Upper/LowerSlash, UpperBack/LowerBack, Horizontal/Horizontal, Vertical/Vertical).
- Detection blocks are derived from tracks sharing edges without block boundaries; a block boundary must be on a cell edge, and signals attach only to block-boundary edges (p.11). Crossings have no signal or gap at the crossing.
- Labels: one section/tile name per cell, placed by a position code ("upcent", "leftupper", etc.; p.81); text may spill into neighbouring cells; train labels display above the track so the manual advises placing names and signals below the track line.
- Signal icons: placed in the cell tile by the same placement codes ("Left...", "Low...", etc.) with a facing direction; triangle or tee base; signal is "facing out of the block it guards".
- Station/depot: a solid box icon in the cell, colour selectable; no operational effect. Name text for siding/station/territory via the Name detail.
- CATS rendering: it compresses columns without diagonals or labels to half width (override: Compress Screen), auto-wraps wide plans into bands (override: Automatic Wrapping), so author the plan linear, or switch both off; grid size option is disabled (cell square). Two track ends that do not touch can be declared logically adjacent (p.~66, "join" mechanism), so non-adjacent bands (helix, level jump) can be connected by a logical link rather than drawn.
- Not found in manual: a maximum grid size; any way to draw a curve; vertical or non-45 diagonals; text rotation.
- Implication for the schematic tool: use integer rows/columns, 45-degree legs only, one-row-per-offset steps, labels in a cell beside the track (below preferred), and put helix connections as logical joins.

## 7. "Drawing with SAT" (Luteberget and Johansen, Formal Aspects of Computing 2021)
Access: the Springer URL returns a bot page; I read Chapter 6 "Drawing schematic plans" of the thesis, which is the same method (PDF https://luteberget.github.io/preprints/luteberget-thesis-plain-b5-2019-09-17.pdf, pp.141-159, TEXT). The thesis page says the FAC paper is the published form. Marking: thesis chapter TEXT; journal article UNVERIFIED (not opened).
Hard constraints, from railway signalling engineers (RailCOMPLETE):
- (A) Octilinearity: only horizontal and 45-degree lines; vertical allowed only for balloon loops. The tilt is "a visual clue that the drawing is not fully geometrically accurate".
- (B) Linear order: nodes ordered left to right by mileage (x non-decreasing along the reference axis).
- (C) Node shapes: a switch's left/right legs must stay left/right as in geography; and the straight leg of a switch should stay straight relative to the trunk.
- (D) Uniform spacing: parallel tracks on integer y levels; x needn't be integer.
Soft constraints (optimised, priorities selectable, lexicographic): (i) width and height, (ii) total length of diagonal segments, (iii) number of bends. Examples: a signalling schematic minimises diagonals; a dispatcher-station schematic minimises width.
Model facts: nodes are ends, switches (4 classes: in/out by left/right, each with two drawing variants: trunk horizontal or deviating leg horizontal), crossings, flyovers; edges attach to ports. A vertical-order partial order on edges is derived from topology first. Three encodings: LP (up to two bends per edge, poor when ladders), level-based SAT (two bends max, node variants chosen freely, short edges share a level), cross-section/grid SAT (unbounded bends, smallest drawings, slower). Edges are drawn as diagonal-horizontal-diagonal. Performance: level-based fastest; interactive under about 1 s on station-sized graphs.
Symbols and labels: symbols are placed in two rows above and two below each track (levels), ordered by x with difference constraints so they do not overlap; then LP minimises deviation from proportional distance between nodes so physically close symbols stay close. The authors call general label placement a hard problem and use this simplified thin-rectangle approach. Tool built-in symbol styles "simple" and "ertms"; Lua extends.
Scope caveat: "single corridor" assumption - each point can be put on one linear axis; multi-corridor overviews need another method (the thesis cites metro map approaches).

## (a) Updated style rules, with supporting examples
1. One straight horizontal line per main (per deck or per route), several lines stacked as bands; branches and passing sidings leave and rejoin at 45 degrees; vertical segments only for loops. NEK M1; PRR GO 418 (1.3); Harold (2); SAT constraint A.
2. Sidings drawn parallel and shifted one row at 45 degrees, short length, joined by switch glyphs at both ends; yard ladders as thin parallel lines converging at 45 degrees. NEK; PRR Floreffe (1.4); Conemaugh (1.5).
3. Line weight: prototype sheets use one weight (1.1, 1.3) or slightly heavier mains (1.4); the model examples use heavier main, thin siding (pass 1 St Charles fascia). Use two weights only: main heavy, everything else about half. 
4. Name every track in place on the line with direction ("NO.1 EWD MAIN TRK. ->", "Track 2", "MEC"). 1.1, 1.3, NEK.
5. Open ends: arrow or filled dot, plus "To X" text; a continuation to another band uses a circled letter. 1.1, 1.3, NEK, Harold.
6. Mileposts as diamond-on-stalk ticks at equal spacing or as circled numbers with feet between; on a schematic, keep the tick and number but do not scale spacing to distance. 1.3, 1.4, 1.2.
7. Control points and interlockings: name in quotation marks beside a tower box; square brackets across the tracks for interlocking limits; yard limits per the 1941 legend symbol. 1.2, 1.3, 1.1.
8. Signals as small flag glyphs at the track, arrow in facing direction, number beside; switches numbered at the point. 1.1, 1.3.
9. Hidden or staging: dashed; staging group in a box listing the off-layout places. NEK M1. Helix drawn as labelled rings or a labelled connector with up/down arrows; elevation in a box. M3, M4.
10. Title block bottom right in a ruled border: railroad, area, sheet, date; "last corrected" and "built or rebuilt" dates; revision dates. 1.3, 1.4, pass-1 Walbridge.
11. Direction: state it on the sheet: east to the right with "WEST | EAST" arrows, or arrows on tracks; keep it fixed across sheets (PRR book was inconsistent, which readers noted). St Charles M2, 1.3.
12. Dimensions: if shown, footage between interlocking points on a ruled dimension line at the top. 1.1.
13. Capacity: put car capacity next to the siding name or in a boxed bracket with total (Conemaugh 1.5; timetable tables in pass 1); model examples still omit it.
14. Text sans-serif caps for tracks and signals, mixed case for towns; rotated 90 degrees only where a leg is vertical. 1.3, 1.4, NEK.
15. Black on white first; colour only redundant (territory colour in pass 1, club colour in M5). Colour-only coding fails when photocopied (M5).
16. Drop non-operating detail (not all tracks shown; just passing sidings and main yards). NEK author's note.

## (c) CATS grid constraints
See section 6 (grid of square cells, six mid-edge segments, 45-degree steps over one column and two cell rows, edge-based connectivity, switch = 2-3 tracks on an edge, crossing recognition rules, signals on block-boundary edges with placement codes, one name per cell, logical joins for non-adjacent edges, compress/wrap options).

## (d) SAT paper readability criteria
Section 7: hard A octilinear, B left-to-right order, C switch shape and straight-leg preservation, D integer parallel spacing; soft: width, height, diagonal length, bends (ordered, user-prioritised); symbols in two rows above and below, non-overlapping, kept near proportional position; single-corridor limit.

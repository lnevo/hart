01The roster on the throttle

Tool
Claude
When
November 2026
Status
Public; in service

The job

A locomotive has to be known in the DecoderPro roster and in the command station, and there are two kinds of throttle in people’s hands. WiThrottle throttles on phones take their list from the JMRI roster. LCC throttles take theirs from the command station, a TCS CS-105, which speaks LCC. Both should list every locomotive by name with the function buttons labelled. Keeping the command station in step with the roster by hand does not last.

What AI did

DecoderPro can copy a roster entry into the command station only if the command station already has a train for that address, and there is no way to say “create it”. So the copy runs from inside JMRI instead: it reads the roster, asks the command station to create any train it is missing, and writes the name and function labels into each one. It refuses to apply anything when no CS-105 answers on the LCC bus. A small tool restarts the command station over LCC, and a helper builds a consist, with CSX 2121 leading and 2738 following in reverse, headlight linked.

What came out

Every roster locomotive on the CS-105 by name, with the right buttons, so the LCC throttles list the same locomotives as the WiThrottle ones. The script is now its own public project so other modelers can use it.

Some things only showed up by trying. The command station keeps a train through a restart only once the train has a name; four came back blank the first time. The roster IDs became road and number, such as CSX 2121, because that is what the WiThrottle phone throttles show, and the CS-105 train names were matched to them. And the script that copies the roster to the Windows computer reported success for a while and delivered nothing, because the files were packed with absolute paths. Now the copy checks every file afterwards and fails loudly if any is missing.

Verdict
  • Worked well: a script inside JMRI that creates the missing command-station trains and copies the roster into them.
  • Lesson: a script that says it worked is not proof. Check the far end.

See it: jmri-cs105-roster-sync on GitHub

02Roster photos

Tool
Claude
When
November 2026
Status
Thirteen locomotives so far

The job

The roster, the cards and the website all want a picture of each locomotive, and they should look like a set.

What AI did

A small tool cleans each photo the same way: level, a loose crop with room round the locomotive and track, colour and exposure left alone, a smooth grey backdrop and a soft shadow under the track. The two halves of a consist face opposite ways.

What came out

Thirteen locomotives with a photo in the roster, installed on every computer; the newest are on the site too.

Verdict
  • Worked well: a consistent look once the style was fixed.
  • Needed me: the style. The car-photo tool, tried first, cropped too tight, tilted a level photo and blew out the exposure, and a pure white backdrop was rejected. I approve the sheet before anything is recorded.

03Speed matching

Tool
Claude
When
November 2026
Status
2738 matched to 2121 in both directions; first coupled run to come

The job

Two locomotives that run at different speeds cannot work together; one drags the other. I wanted CSX 2121 and 2738 to run as a pair.

What AI did

A program running inside JMRI sets a locomotive to a throttle step, lets it run through the block sensors and times each block, step after step, with no hands on the throttle. Block lengths now come from the track plan and were checked against timed passes. Both locomotives were measured in both directions on 13 November 2026, 2738 was adjusted to match 2121, and the two were compared stopping.

The 13 November 2026 runs

2738 now runs within 4 per cent of 2121 at every step from 24 up, in both pairings of the two locomotives (most steps within 2 to 3 per cent). Step 16 is 2 per cent fast in one pairing and 6 per cent fast in the other. The locomotives face away from each other in a consist, so 2121 forward runs with 2738 reverse and the other way round.

Speeds are in mm/s, as written to the roster. The tolerance is 5 per cent: one step repeats to about 2 per cent between runs, and to 6 per cent at the slowest steps. Step 8 is creep, where 2738 is about 20 per cent fast and stays so.

2121 ran 3 to 10 per cent faster in reverse than forward, while 2738 ran evenly both ways. Raising only 2738’s forward trim brought 2738 forward up to 2121 reverse; the other pairing already matched.

Stopping from step 32 and from step 96 on the same track, with the same trigger, every block lit within 0.2 seconds of the other locomotive, and both came to rest in the same block. 2121 slows more gently than its settings predict, and 2738 matches it. The test of the coupled pair did not run cleanly, so the solo match stands for it.

Both roster entries now hold the measured speed profile, eight points each. 2121 was not changed.

Two runs are marked: the 11:43 run of 2738 forward is not used, because before a fix the locomotive ran the opposite way to the one asked, and the 12:51 run of 2738 forward is superseded by the run after the CV66 change.

The first run, 8 November 2026

The first program set each locomotive to a throttle step and timed laps of the whole loop. Both topped out at about the same speed, but 2738 ran at only 47 to 74 per cent of 2121’s speed through the lower steps. Its settings explained why: the speed table was switched off and it had no momentum.

2738 was matched to 2121, momentum included, with a calculated speed table programmed on the programming track; every value read back correctly. Measured again at steps 24, 48 and 126 it ran within 1.2 per cent of 2121, and about 5 per cent fast at step 12. At step 96 the two stopped within a tenth of a second of each other and started within three tenths. The two were timed running in opposite directions then, which the 13 November runs corrected.

What came out

A matched pair, ready to be tried coupled, and a method to repeat for the other fifteen locomotives.

Verdict
  • Worked well: hours of unattended, repeatable measuring, a speed table worked out from the numbers rather than by feel, and one trim setting that matched both directions.
  • Be honest about: step 8 stays about 20 per cent apart, and step 16 is 6 per cent apart in one pairing. Block lengths now come from the track plan and were checked against timed passes; both directions were measured. Some loop 2 lengths are still estimates, so scale miles an hour is approximate. A block lighting again behind the locomotive can be taken as the next block, which is not fixed. The coupled stop test has not run cleanly.

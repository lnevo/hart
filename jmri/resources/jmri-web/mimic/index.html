Served by JMRI. State comes from the JMRI JSON WebSocket; clicks go to mimic_relay.py, which publishes LCOS status track/turnout/{addr} (plus FB N/R sensors for TWOSENSOR plants) and occupancy track/sensor/{addr}, retained. It never publishes track/cmd (motors stay put). The main and upper levels run on virtual JMRI turnouts and sensors (IT:HART:C3:*, IS:HART:C3:B:*), so their clicks set those in JMRI directly; nothing reaches MQTT or the field.

# Model Railroad Engineer – Electrical: SOQ draft

Draft Statement of Qualification for the NMRA Achievement Program certificate, prepared 2026-11-14. Checklist and rules: [www/ap/index.html#electrical](../../../www/ap/index.html) (live at hartrailroad.com/ap/#electrical).

| File | What it is |
|------|------------|
| `MRE-Electrical-SOQ-form.pdf` | The NMRA 2025 fillable SOQ form with the chosen items ticked, Region (NER) and Division (Sunrise Trails) filled. Personal fields are blank on purpose: fill them on your own copy, never in the repo. |
| `MRE-Electrical-SOQ-package.pdf` | Form + description + staging track plan + schematics (wiring deck pages 1, 2, 4, 5, 6 and the schematic deck's summary, turnout and staging node pages). |
| `attachment.html` | Source of the description (sections A to C). Print to PDF with headless Chrome and rebuild the package after editing. |

Items chosen: Requirement 2 turnout, crossover, other (two reversing sections on auto-reversers: Main West, K-1 / K-2); Requirement 3 (a) turnout position indication, (b) track occupancy, (r) CTC system.

Still open (highlighted yellow in the description):

- Name the passing siding for Requirement 1b.
- Gaps in one rail or both at block ends, and feeder spacing.
- Frog feed method and turnout make; which auto-reverser feeds each reversing section.
- Draw C6 (crossover gaps and frog feeds), C7 (Main West and K-1 / K-2 gaps and auto-reverser feeds), and mark block gaps and feeders on the staging plan for the Requirement 4 propulsion schematic.
- Member details, then the witness (Region AP Manager or designee) signs.

Sources: `docs/wiring/Layout Documentation.pptx`, `docs/wiring/Wiring_Schematic.pptx` (exported with Keynote), `www/build/track-plan.html`, form from nmra.org/electrical.

B. Requirements 2 and 3: the six items

Requirement 2a · Turnout

Twenty powered turnouts on the staging level, all with wired, powered frogs. Each is thrown by a slow-motion switch machine (the decks call them MP4) from a 12 V output on its LCOS node. The machine's auxiliary contacts report Normal and Reverse to the node's input board. State the frog feed (machine contacts or a frog juicer) and the turnout make.

Commercial components: turnouts (make), MP4 switch machines, LCOS DNOU8 output and DNIN8 input boards. Schematics C3, C4.

Requirement 2c · Crossover

Crossovers at Switches 23 (23a/23b) and 35 (35a/35b) in staging, and the Switch 7 crossover. Each half is a powered-frog turnout on its own machine and both halves are worked together; the rail between the two frogs is gapped so that each frog takes its own polarity. Each half is a separate detection section (OS 23a, OS 23b, OS 35a, OS 35b). Commercial components as for turnouts. Schematic C6.

Requirement 2 · Other: reversing sections on auto-reversers

Main West, and the K-1 / K-2 loop legs, are each gapped in both rails at both ends and fed through an auto-reverser, which swaps the section's polarity when a train bridges a gap. The sections are long enough to hold a whole train between the gaps. Confirm which auto-reverser (PSX-AR or AR-10) feeds each section. Schematic C7.

Requirement 3a · Electrical turnout position indication (4+ turnouts)

Every staging turnout shows its position in two places. On the fascia, a Touch Toggle button lights to show the route; a Universal Translator drives the lamp from the switch machine's own contact, so the indication follows the points even when the turnout is thrown from a DCC throttle or the computer. On the CTC desks, the same contacts, read by the LCOS input boards and passed to JMRI over MQTT, light the Normal and Reverse lamps for each switch. Commercial components: Touch Toggles and Universal Translators, LCOS DNIN8 input boards. Schematics C3, C4, C8.

Requirement 3b · Track occupancy indication (5+ blocks)

57 blocks are detected by current transformers on their feeders (DNCT2B two-channel detectors, read by the LCOS node in that area). Occupancy is shown on the CATS CTC desk, the USS CTC board and the JMRI Layout Editor panel, each block as a lamp on the track it shows. Commercial components: DNCT2B / DNCTA detectors, LCOS nodes. Schematics C2, C5.

Requirement 3r · CTC system

A centralized traffic control system designed and built for this railroad, not a commercial unit. A dispatcher's desk (CATS, laid out as a Union Switch & Signal Digicon machine, with a second USS-style board as the alternate) lines routes and clears signals at each control point. Field state comes back from the layout: switch positions from the machine contacts, block occupancy from the detectors. The desk refuses a route through an occupied block or a switch locked by another route, and signal logic sets the aspects. The panels, interlocking tables and signal logic were drawn up and configured for HART; JMRI and CATS supply the software platform. Components: JMRI and CATS (free software), LCOS nodes, MQTT link. Schematic C8.

Also available if wanted: computerized block detection (3t), computerized operation (3u) and a computer-to-railroad interface (3v, the bridge that carries LCOS radio traffic to MQTT).

C8 · CTC system

A route request from the desk becomes turnout and signal commands in JMRI; JMRI sends them over MQTT to the LCOS node beside each switch, which drives the machine and the signal lamps. The machine's contacts and the block detectors report back the same way, and the desk only clears a signal once the switches are confirmed and the blocks ahead are clear.

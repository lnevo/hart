# docs/ap

Records for the NMRA Achievement Program certificates the owner is working toward, currently the Model Railroad Engineer - Electrical package.

| Folder | What it holds | State |
|--------|---------------|-------|
| `electrical/` | Statement of Qualifications (SOQ) for the Electrical certificate: `soq.html` and `soq.css` source, the archived builders (`archive/code/ap-electrical/`), the built PDF, `photos/` and `drawings/` | Submitted and frozen on 2026-11-15; `SUBMITTED.md` explains why the build refuses to run |

Inside `electrical/`, `README.md` lists every file, `SUBMITTED.md` records the hashes of the copies sent, and `PHOTO_PUNCH_LIST.md` is the finished list of photographs the SOQ needed. The public site page for the certificate is `www/ap/index.html`.

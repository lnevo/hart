# Logo and template sources

Where every file under `operator_logos/` came from. The logos identify real railroads and
industries on a model railroad's cards, waybills, sticker sheets and website; they are
trademarks of their owners and are used here for reference only. Any owner can ask for a
file to be removed.

Status: **confirmed** (checked against the source page), **likely** (same artwork found, exact
copy not verified), **not recorded** (a web image whose origin was not written down when it
was saved). "Public domain" for a Wikimedia Commons logo is the Commons copyright tag; the
trademark still applies. Unless a date is given, a file arrived with the first commit of the
car-card tooling on 2026-08-31.

Checked 2026-11-09 by comparing every image by eye, by checksum and against Wikipedia and
Commons file pages.

## Templates

The car cards, waybills and sticker sheets are printed on Apostrophe Games' free poker-size
sticker template (9 per US Letter page): https://www.apostrophegames.com/pages/blank-sticker-templates

It is their file and their page states no terms for passing it on, so it is **not in the repo**.
The card tools read the Word version from `card_pipeline/assets/Poker Size Sticker Sheet Template.docx`
(gitignored); download it once from that page and save it under that name. Without it the tools
stop and print the link. The PDF version is not used.
